# tg-commenter 💬

Помощник, который следит за выбранными Telegram-каналами и при новом посте
предлагает доброжелательный комментарий (через ChatGPT API). Ты подтверждаешь,
правишь или пропускаешь — и комментарий публикуется **с твоего одного
аккаунта**, в ветке обсуждения канала. Работает через прокси.

> Один аккаунт, человек принимает решение. Так задумано: это инструмент,
> чтобы по-человечески поддерживать друзей, а не накрутка. Не злоупотребляй —
> массовый авто-постинг с пачки аккаунтов нарушает правила Telegram и ведёт
> к блокировкам.

## Что нужно

- Python 3.10+
- Твой Telegram-аккаунт (API ID/HASH с https://my.telegram.org)
- Ключ OpenAI API
- (необязательно) прокси SOCKS5/HTTP/MTProto

## Установка

```bash
cd tg-commenter
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Скопируй примеры конфигов:
   ```bash
   cp .env.example .env
   cp config.example.json config.json
   ```
2. В `.env` впиши `API_ID`, `API_HASH`, `OPENAI_API_KEY` и, если нужно,
   блок `PROXY_*`.
3. В `config.json` укажи:
   - `persona_prompt` — как аккаунт должен себя вести в комментариях;
   - `channels` — список каналов (`@username` или ссылки `https://t.me/...`);
   - `auto_post` — `false` (с подтверждением, рекомендуется) или `true`;
   - `min_seconds_between_comments` — пауза между комментариями.

### Session-файл
- **Если файла ещё нет** — просто запусти программу: Telethon попросит номер
  телефона и код, и создаст `account.session` сам.
- **Если файл уже есть** — положи его в папку `tg-commenter/` и укажи имя
  (без `.session`) в `SESSION_NAME`. Важно: session-файл должен быть создан
  с теми же `API_ID`/`API_HASH`.

### Прокси
В `.env`:
```
PROXY_TYPE=socks5        # socks5 | socks4 | http | mtproto | none
PROXY_HOST=1.2.3.4
PROXY_PORT=1080
PROXY_USER=...           # если есть авторизация
PROXY_PASS=...
PROXY_SECRET=...         # только для mtproto
```

## Запуск

```bash
python main.py
```

Дальше при каждом новом посте увидишь:
```
Новый пост в «Канал»:
────────────────────────
<текст поста>
────────────────────────
Предложенный комментарий:
  <вариант от GPT>

[Enter] отправить · [e] изменить · [s] пропустить:
```

## Частые вопросы

- **Комментарий не отправляется** — у канала должны быть включены
  обсуждения (linked discussion group). Без них комментировать нельзя.
- **FloodWait** — Telegram просит подождать; программа сделает паузу сама.
  Не убирай `min_seconds_between_comments`, иначе легко словить ограничения.
- **Безопасность** — `.env`, `config.json` и `*.session` уже в `.gitignore`,
  в репозиторий не попадут. Никому не передавай session-файл — это полный
  доступ к аккаунту.
