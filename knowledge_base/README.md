# База знаний компании

Сюда складываешь документы, на основе которых бот консультирует клиентов.

## Как это работает
- Поддерживаются файлы `.md` и `.txt`.
- Все файлы из этого каталога склеиваются и попадают в «голову» бота.
- Файл `README.md` (этот) **не** попадает в бота — он только для тебя.
- После изменения файлов вызови `POST /admin/reload-kb` (или перезапусти
  сервис), чтобы бот подхватил правки.

## Что сюда положить (примеры файлов уже лежат рядом — отредактируй их)
- `01_o_kompanii.md` — кто вы, чем занимаетесь, контакты, график.
- `02_uslugi_i_ceny.md` — список услуг/товаров, цены, что входит.
- `03_faq.md` — частые вопросы и ответы.
- `04_skidki_i_usloviya.md` — условия оплаты, доставки, гарантии, акции.

Можешь добавлять любые свои файлы — главное, пиши их понятным языком,
как будто объясняешь новому сотруднику. Чем конкретнее факты и цены —
тем точнее бот. То, чего нет в базе, бот придумывать не будет — он
переведёт клиента на оператора.

## Чего НЕ стоит писать
- Секреты, пароли, внутренние доступы.
- Информацию, которую нельзя показывать клиентам.
