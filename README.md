# Immersive WebGL Site

Стартовый каркас immersive-сайта в духе [activetheory.net](https://activetheory.net):
fullscreen WebGL-канвас, GPU-частицы, bloom-постобработка, инерционный скролл и
реакция камеры на мышь.

## Стек

- **Three.js** — 3D-рендер и шейдеры
- **GLSL** — движение 80k частиц целиком в вершинном шейдере
- **EffectComposer + UnrealBloom** — свечение/постобработка
- **GSAP** — анимация intro
- **Lenis** — инерционный (smooth) скролл
- **Vite** — дев-сервер и сборка

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (по умолчанию http://localhost:5173).

## Сборка

```bash
npm run build      # в папку dist/
npm run preview    # локальный предпросмотр сборки
```

## Где что менять

| Файл | За что отвечает |
|------|-----------------|
| `src/main.js` | сцена, частицы, шейдеры, постобработка, скролл/мышь |
| `src/style.css` | HTML-слой поверх канваса |
| `index.html` | разметка контента и оверлея |
