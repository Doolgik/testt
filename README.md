# NOVA Consulting Group — премиальный сайт

Многостраничный корпоративный сайт консалтинговой компании в нише цифровой
трансформации: внедрение AI, автоматизация процессов, аналитика и BI,
корпоративная автоматизация. Сделано на **Next.js 14 (App Router)** +
**TypeScript** + **Tailwind CSS**.

## Дизайн-система

| Токен | Значение | Назначение |
|---|---|---|
| `canvas` | `#F5F4F1` | Основной фон |
| `surface` | `#FFFFFF` | Карточки, панели |
| `ink` | `#111111` | Основной текст |
| `muted` | `#5E5E5E` | Вторичный текст |
| `accent` | `#0F5EFF` | Главный акцент / CTA |
| `accent-soft` | `#D9E5FF` | Дополнительный акцент |
| `line` | `#E6E6E6` | Линии и границы |

**Типографика:** Manrope (заголовки, `--font-manrope`) + Inter (текст,
`--font-inter`), подключаются через `next/font/google`. Шкала — fluid
(`clamp`), см. `tailwind.config.ts` (`text-hero`, `text-section`, `text-sub`).

**Сетка:** 12 колонок, `max-width 1400px` (`.container-x`). Вертикальный ритм
секций `.section` / `.section-tight` (140–200px между блоками).

**Анимации:** reveal-on-scroll через `IntersectionObserver`
(`src/components/Reveal.tsx`), мягкие easing-кривые
`cubic-bezier(0.16,1,0.3,1)`, поддержка `prefers-reduced-motion`.

## Страницы

- `/` — главная (hero, интро-тезис, метод, интерактивные услуги, бизнес-эффекты,
  философия, отзывы, финальный CTA)
- `/services` — подробное раскрытие 5 направлений (этапы, результаты, цены)
- `/about` — история, подход, принципы, команда
- `/cases` — 3 концептуальных кейса (задача / подход / результат)
- `/contacts` — контакты, карта, форма заявки

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
```

Бэкенд не требуется: форма заявки работает как демонстрационная
(клиентская валидация + имитация отправки), изображения — встроенные
SVG-композиции в едином брендовом стиле (`src/components/Visuals.tsx`).
